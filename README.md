## 🎯 Objetivo General

Profundizar en los conceptos básicos de la **Ingeniería del Software** y su aplicación al desarrollo de software para la Web, incluyendo técnicas y herramientas para aplicar metodologías de desarrollo que establezcan cómo ha de realizarse el proceso software.

---

## 🗂️ Contenidos del Curso

### Módulo 1 — Introducción a la Ingeniería del Software

#### 1.1 Conceptos Generales
- Conceptos y definiciones fundamentales
- Ciclo de vida del software
- Metodologías: estructurada, orientada a objetos, web
- Ingeniería del software asistida por computador (CASE)

#### 1.2 Análisis de Sistemas de Información
- Principios del análisis e ingeniería de requisitos
- Análisis de funciones, datos y orientado a objetos
- Diagramas UML para el análisis de sistemas

#### 1.3 Diseño de Software
- Enfoques y niveles de diseño
- Diseño de interfaz de usuario y diseño arquitectónico
- Técnicas de diseño estructurado y orientado a objetos
- Diagramas UML para el diseño

#### 1.4 Prueba del Software
- Pruebas unitarias, de sistema, de implantación
- Pruebas de aceptación y de regresión

---

### Módulo 2 — Gestión de Proyectos de Ingeniería del Software

#### 2.1 Introducción a la Gestión de Proyectos Informáticos
- Objetivos, temporalidad y presupuesto
- Ciclo de vida de un producto informático
- Etapas: Iniciación, Planificación, Ejecución, Control, Cierre

#### 2.2 Definición del Problema y Estrategias de Solución
- Objetivos y especificaciones del producto
- Requerimientos de los interesados
- Búsqueda y desarrollo de estrategias

#### 2.3 Planificación del Tiempo
- Representación gráfica de tareas
- Técnica PERT y camino crítico
- Análisis de tiempos

#### 2.4 Hitos, Documentos y Revisiones
- Diagrama de Gantt
- Hitos y fechas límite
- Documentación técnica como herramienta de seguimiento
- Gestión de conflictos entre actividades

#### 2.5 Factores de Productividad
- Métricas de productividad del software
- Herramientas de mejora
- Modelo COCOMO (Constructive Cost Model)
